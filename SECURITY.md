# Security

The app binds to `127.0.0.1` and rejects non-loopback Streamlit configuration. It keeps documents
in memory for the Streamlit session. The OpenAI client uses `store=False` and requires an official
OpenAI HTTPS endpoint and `OPENAI_API_KEY`.

The app treats document text as untrusted data. The parser prompt tells the model to transcribe,
not follow, instructions printed inside a document. Downloadable HTML is rendered locally,
sanitized with `nh3`, and contains no JavaScript. It permits only image data generated by the app.

Limits include 200 MB per file, 20 files, 100 selected pages, a 20-million-pixel raster bound, four
zoom crops per page, and two zoom rounds. Model-generated text and bounding boxes may be wrong and
must be reviewed before consequential use.

Report vulnerabilities privately to the repository owner. Do not include documents, API keys, or
other sensitive data in a report.
