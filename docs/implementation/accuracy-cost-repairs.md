# Accuracy, uncertainty and cost repairs

## Implemented

- Shared production extractor construction for UI, CLI and evaluation.
- No automatic acceptance from layout confidence, model self-audit, or missing evidence.
- Independent crop verification, supported corrections, and redaction of disputed lines/cells.
- JSON v3 with explicit nullable value states, candidate evidence and crop hashes; v2 readers retained.
- Confidence report v2 and manifest v9, with explicit legacy readers and review requirements.
- Foreground coverage checks, bounded recovery regions, and visible unresolved coverage.
- Eight Sol fields per document, sixteen escalated segments per page, bounded retries.
- Job-scoped verified-read reuse and exact session-local batch reuse; reset clears retained content.
- Persisted budget reservations, provider token preflight, conservative unknown-outcome charges,
  restart recovery, and an exclusive ledger lock.
- Per-request long-context cost accounting; aggregate small requests do not incur that premium.
- Evaluation configuration, route comparisons with a shared budget, resume checks, and offline calibration.
- Family-grouped calibration; promotion requires verified references, exact values and no observed
  false accepts. Local routes also require paired recall preservation.
- Restored test discovery, PDF pixel-bound handling, annotation-failure reporting and provenance fixes.
- Declared the missing PaddleX OCR dependencies; recorded actual layout failures and full-page fallbacks.

## Runtime finding

PP-StructureV3 initially failed because `paddlex[ocr]` dependencies were absent. After installing
the declared extra with uv, the GPU runtime stalled inside Paddle while loading `cublas64_12.dll`.
The active environment was rebuilt using `uv sync --extra cpu --frozen`; the old environment
remains preserved in the ignored `.venv-cuda-stalled-20260905` directory. No CUDA environment
variables or security settings were changed.
GPU startup remains unverified; the completed evaluation used CPU. The 14-page run took about
47.6 minutes, so CPU throughput remains a practical limitation.

CPU inference exposed a separate Paddle 3.3 oneDNN `ConvertPirAttribute2RuntimeAttribute`
failure. The Windows CPU adapter now uses standard kernels, and real inference passes.
Parsed blocks omit confidence, so the adapter now joins uniquely matching detector boxes
within one pixel of the rounded coordinates. Missing or ambiguous matches retain zero scores.
These detector scores affect routing only, never accepted-value confidence.

A 300-DPI native run exceeded available memory before making paid requests. Layout input now
has a 1,600-pixel longest-side bound, with the affine mapping composed through the resize.
Full-resolution verification pixels are retained. The previous run was stopped; its interrupted
directory is `evaluation/validation/20260905T094900Z-8999fd5f91`.
